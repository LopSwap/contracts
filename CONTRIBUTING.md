# Contributing to Lopswap

We welcome contributions from the community!
To keep the process smooth and productive, please follow these guidelines.

---

## How to Contribute

1. **Open an Issue**
   - If you spot a bug, have a feature request, or want to propose an improvement, please open an issue first.
   - Clearly describe the problem and expected behavior.

2. **Fork & Branch**
   - Fork the repository to your account.
   - Create a new branch for your work:
     ```
     git checkout -b feature/my-change
     ```

3. **Code Style & Tests**
   - Keep the code clean and consistent.
   - Run existing tests and add new ones where needed.
   - Ensure your changes don’t break the build.

4. **Commit Messages**
   - Use clear, descriptive commit messages.
   - Example:
     ```
     fix: handle expired pools correctly
     feat: add support for Permit2 approvals
     ```

5. **Pull Request**
   - Push your branch and open a PR against `master`.
   - Provide a short description of your changes.
   - Link to related issues if applicable.
   - Be ready to respond to feedback from maintainers.

---

## Code of Conduct
By contributing, you agree to follow our community guidelines:
- Be respectful and constructive in discussions.
- Focus on improving the project for everyone.

---

## Questions?
If you’re unsure about anything, feel free to open a discussion or ask in the issue tracker.
We’d rather help early than after a lot of work has gone in the wrong direction.
